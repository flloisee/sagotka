  <span style="display: block; font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 11px; letter-spacing: 0.08em; text-transform: uppercase; color: #de5d50; font-weight: 600; margin-bottom: 6px;">Architecture</span>
  Monorepo architecture
</h2>

<pre style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; line-height: 1.6; color: #1a1413; background: #f6f2f0; border: 1px solid #d6d0cc; border-radius: 8px; padding: 16px 20px; overflow-x: auto; margin: 12px 0;">npm workspaces
   │
   ├── shared  ── raw TypeScript source (zod schemas, types, validateAnswer, quiz grading)
   │                consumed directly by both server and web — never built
   │
   ├── server  ── Express 5 API (tsx, ESM NodeNext) on port 8787
   │                node:sqlite DatabaseSync, argon2id, cookie sessions, SMTP, multer
   │
   └── web     ── React 19 SPA (Vite) on port 5173
                    Tailwind v4 via @tailwindcss/vite, react-router-dom v7</pre>

<div style="background: #ffd3c3; border-left: 3px solid #de5d50; border-radius: 8px; padding: 14px 18px; margin: 16px 0; font-family: ui-sans-serif, system-ui, -apple-system, 'Segoe UI', Roboto, Inter, 'Helvetica Neue', Arial, sans-serif; font-size: 14px; line-height: 1.55; color: #6f6763;">
  <span style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 11px; letter-spacing: 0.08em; text-transform: uppercase; font-weight: 600; color: #de5d50;">Shared is never built</span><br>
  The <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">shared</code> package ships as raw TypeScript and is consumed directly by both server and web — there is no build or watch step.
</div>

<div style="font-family: ui-sans-serif, system-ui, -apple-system, 'Segoe UI', Roboto, Inter, 'Helvetica Neue', Arial, sans-serif; font-size: 15px; line-height: 1.55; color: #6f6763;">The <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">shared</code> package is the single source of truth for the domain: TypeScript interfaces (<code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">Form</code>, <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">Question</code>, <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">FormResponse</code>, …), zod schemas for every API request body, answer validation, and quiz grading logic. Because it ships as raw <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">.ts</code>, there is no build or watch step — the server imports it through <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">@sagotka/shared</code> (tsx resolves the barrel <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">shared/src/index.ts</code>) and the web app aliases it directly in <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">web/vite.config.ts</code> and <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">web/tsconfig.app.json</code>. New shared code just needs to be exported from the <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">shared/src/index.ts</code> barrel.</div>

<div style="font-family: ui-sans-serif, system-ui, -apple-system, 'Segoe UI', Roboto, Inter, 'Helvetica Neue', Arial, sans-serif; font-size: 15px; line-height: 1.55; color: #6f6763; margin-top: 16px;">During development the Vite dev server proxies <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">/api</code> and <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">/uploads</code> to the Express server, so the browser always talks to a single origin. In production, <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">npm run build</code> compiles the web app to <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">web/dist</code>, and the Express server serves it (with an SPA fallback) when it detects that directory at boot.</div>

<div style="background: #ffd3c3; border-left: 3px solid #de5d50; border-radius: 8px; padding: 14px 18px; margin: 12px 0; font-family: ui-sans-serif, system-ui, -apple-system, 'Segoe UI', Roboto, Inter, 'Helvetica Neue', Arial, sans-serif; font-size: 14px; line-height: 1.55; color: #6f6763;">
  <span style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 11px; letter-spacing: 0.08em; text-transform: uppercase; font-weight: 600; color: #de5d50;">ESM import extensions</span><br>
  The server is ESM <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">NodeNext</code>: local imports use <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">.js</code> extensions (<code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">import { db } from './db.js'</code>) even though the files are <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">.ts</code>. tsx resolves them, but a typecheck pass will <strong style="color: #1a1413;">not</strong> catch a missing <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">.js</code> extension — the error only appears at runtime. Run the server (or hit a route) to verify wiring.
</div>

<div style="border-left: 3px solid #de5d50; padding: 6px 0 6px 18px; margin: 12px 0; font-family: ui-sans-serif, system-ui, -apple-system, 'Segoe UI', Roboto, Inter, 'Helvetica Neue', Arial, sans-serif; font-size: 14px; line-height: 1.55; color: #6f6763;">
  <span style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 11px; letter-spacing: 0.08em; text-transform: uppercase; font-weight: 600; color: #de5d50;">Shared is never built</span><br>
  It is imported as raw TypeScript by both tsx and the Vite alias. Any new shared code must be exported from <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">shared/src/index.ts</code> or it won't be visible to either consumer.
</div>

<div style="border-left: 3px solid #de5d50; padding: 6px 0 6px 18px; margin: 12px 0; font-family: ui-sans-serif, system-ui, -apple-system, 'Segoe UI', Roboto, Inter, 'Helvetica Neue', Arial, sans-serif; font-size: 14px; line-height: 1.55; color: #6f6763;">
  <span style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 11px; letter-spacing: 0.08em; text-transform: uppercase; font-weight: 600; color: #de5d50;">Data directories are ephemeral</span><br>
  <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">server/data/</code> and <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">server/uploads/</code> are gitignored and recreated on boot. Deleting <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">server/data/sagotka.db</code> wipes all forms, users, and responses; there is no backup or export mechanism.
</div>

<div style="border-left: 3px solid #de5d50; padding: 6px 0 6px 18px; margin: 12px 0; font-family: ui-sans-serif, system-ui, -apple-system, 'Segoe UI', Roboto, Inter, 'Helvetica Neue', Arial, sans-serif; font-size: 14px; line-height: 1.55; color: #6f6763;">
  <span style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 11px; letter-spacing: 0.08em; text-transform: uppercase; font-weight: 600; color: #de5d50;">External hosts / ngrok</span><br>
  <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">web/vite.config.ts</code> has <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">server.allowedHosts</code> containing an ngrok domain (<code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">harmonics-preamble-occupancy.ngrok-free.dev</code>). Any new external testing host must be added there or Vite will refuse connections.
</div>

<div style="border-left: 3px solid #de5d50; padding: 6px 0 6px 18px; margin: 12px 0; font-family: ui-sans-serif, system-ui, -apple-system, 'Segoe UI', Roboto, Inter, 'Helvetica Neue', Arial, sans-serif; font-size: 14px; line-height: 1.55; color: #6f6763;">
  <span style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 11px; letter-spacing: 0.08em; text-transform: uppercase; font-weight: 600; color: #de5d50;">reCAPTCHA in dev</span><br>
  Leave <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">GOOGLE_RECAPTCHA_SECRET</code> (server) and <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">VITE_RECAPTCHA_SITE_KEY</code> (web) unset to skip verification. Set only the server secret and the browser token won't verify, and vice versa — configure both or neither.
</div>

<div style="border-left: 3px solid #de5d50; padding: 6px 0 6px 18px; margin: 12px 0; font-family: ui-sans-serif, system-ui, -apple-system, 'Segoe UI', Roboto, Inter, 'Helvetica Neue', Arial, sans-serif; font-size: 14px; line-height: 1.55; color: #6f6763;">
  <span style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 11px; letter-spacing: 0.08em; text-transform: uppercase; font-weight: 600; color: #de5d50;">OTP codes in dev</span><br>
  Without SMTP credentials the server logs the code to the console (<code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">[otp] code for …</code>). Enable SMTP (Gmail App Passwords are suggested in <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">.env.example</code>) to deliver codes by email and to enable the OTP second-factor on login.
</div>

<div style="border-left: 3px solid #de5d50; padding: 6px 0 6px 18px; margin: 12px 0; font-family: ui-sans-serif, system-ui, -apple-system, 'Segoe UI', Roboto, Inter, 'Helvetica Neue', Arial, sans-serif; font-size: 14px; line-height: 1.55; color: #6f6763;">
  <span style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 11px; letter-spacing: 0.08em; text-transform: uppercase; font-weight: 600; color: #de5d50;">Node version</span><br>
  <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">node:sqlite</code> requires Node 22.5+. On older Node versions the server will crash at import time with an error about the <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">node:sqlite</code> module.
</div>

<div style="border-left: 3px solid #de5d50; padding: 6px 0 6px 18px; margin: 12px 0; font-family: ui-sans-serif, system-ui, -apple-system, 'Segoe UI', Roboto, Inter, 'Helvetica Neue', Arial, sans-serif; font-size: 14px; line-height: 1.55; color: #6f6763;">
  <span style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 11px; letter-spacing: 0.08em; text-transform: uppercase; font-weight: 600; color: #de5d50;">SPA fallback</span><br>
  <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">npm run start</code> only serves the web app if <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">web/dist</code> exists. Run <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">npm run build</code> first for a prod-like single-origin run.
</div>

  Contributing
</h2>

<div style="font-family: ui-sans-serif, system-ui, -apple-system, 'Segoe UI', Roboto, Inter, 'Helvetica Neue', Arial, sans-serif; font-size: 15px; line-height: 1.55; color: #6f6763;">SagotKa is a small, convention-heavy codebase — please read <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">AGENTS.md</code> and <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">design.md</code> before touching code.</div>

<ul style="font-family: ui-sans-serif, system-ui, -apple-system, 'Segoe UI', Roboto, Inter, 'Helvetica Neue', Arial, sans-serif; font-size: 15px; line-height: 1.6; color: #6f6763; margin: 12px 0; padding-left: 24px;">
  <li>Keep <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">shared</code> the single source of truth; export new schemas/types from the barrel.</li>
  <li>Server changes must run under tsx; verify runtime wiring with <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">npm run dev</code>, not just typecheck.</li>
  <li>Database changes are additive only: <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">ALTER TABLE</code> guarded by <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">PRAGMA table_info</code>, never drop or recreate tables.</li>
  <li>Follow the design tokens in <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">web/src/styles/tokens.css</code> — never inline raw colors or ad-hoc fonts. Motion is 150–200 ms, <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">cubic-bezier(0.2, 0.8, 0.2, 1)</code>, honoring <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">prefers-reduced-motion</code>.</li>
  <li>Before submitting, run <code style="font-family: ui-monospace, 'SF Mono', SFMono-Regular, Menlo, Consolas, monospace; font-size: 12.5px; background: #e6e0dd; border: 1px solid #d6d0cc; border-radius: 6px; padding: 1px 5px; color: #1a1413;">npm run typecheck</code>. There are no automated tests, so test flows manually (register → create → publish → fill → review responses) in both light and dark mode.</li>
</ul>
